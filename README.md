# Procurados

Roteiro do Jogo: Procurados
Número de Jogadores: 2 a 4
Duração da Partida: Variável (média de 15-20 minutos)
Gênero: Esconde-esconde com disfarces
Plataforma: Ideal para digital ou presencial com ambiente temático

Objetivo do Jogo
Um jogador é sorteado como o Caçador, enquanto os outros se tornam os Fugitivos. Os Fugitivos devem se esconder e se disfarçar como objetos do cenário. O Caçador precisa encontrá-los antes que o tempo acabe.

Fases do Jogo
1.  Sorteio do Caçador
Aleatoriamente, um jogador é designado como o Caçador.

Os outros jogadores assumem o papel de Fugitivos.

2.  Fase de Preparação (7 minutos)
Os Fugitivos têm 7 minutos para escolher um local no mapa e se disfarçar como um objeto do ambiente (ex: vaso, cadeira, caixa).

Eles não podem se mover após o tempo acabar, a não ser que usem uma habilidade especial (opcional).

3.  Caçada
O Caçador entra no mapa após os 7 minutos.

Ele tem um tempo limitado (ex: 10 minutos) para encontrar todos os Fugitivos.

O Caçador pode interagir com os objetos suspeitos (clicar/tocar) para revelar um disfarçado.

Regras e Mecânicas
Movimentação:

Fugitivos só podem se mover antes dos 7 minutos acabarem.

Opcional: 1 uso de “movimento furtivo” durante a caçada (com risco de ser visto).

Caçador:

Tem número limitado de interações (ex: 15 toques).

Se usar todos e não encontrar todos os fugitivos, perde a partida.

Vencedores:

Se o Caçador encontrar todos os Fugitivos → Vitória do Caçador.

Se ao menos um Fugitivo permanecer escondido até o fim → Vitória dos Fugitivos.

Disfarces e Estratégias
Fugitivos devem escolher objetos que combinem com o cenário.

Mudar de disfarce consome tempo e pode chamar atenção.

Caçador deve observar padrões estranhos no ambiente.

Extras (opcional)
Habilidades Especiais (cada jogador escolhe uma):

Fugitivo: Invisibilidade temporária, movimento furtivo, troca de disfarce.

Caçador: Visão térmica (revela um disfarçado aleatório), sensor de movimento.
